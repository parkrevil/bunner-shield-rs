# X-Powered-By 제거

서버 프레임워크 식별 헤더를 제거합니다.

## 예시
```rust
use bunner_shield_rs::prelude::*;
let shield = Shield::builder().x_powered_by(()).build(); // 옵션 없음
```

## 동작
- 응답에서 `X-Powered-By` 헤더를 제거해, 서버 프레임워크/버전 식별 단서를 줄입니다.
- 일부 프레임워크/미들웨어는 기본적으로 이 헤더를 추가합니다. 본 기능은 최종 단계에서 이를 제거합니다.

## 권장 사항
- 운영 환경에서는 항상 제거를 권장합니다.
- 식별 표식은 공격 표면을 넓히므로, 배너/서명류 헤더는 비공개로 유지하세요.
